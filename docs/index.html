Aristois for 26.3 version

Aristois para Minecraft 26.3 con Fabric: el menú abre sin crash, el X-ray funciona y podés elegir qué bloques esconder o resaltar.

Descargar (Releases) Código en GitHub

Qué arregla

  • Crash al abrir el menú (Shift derecho): Scissor size must be >0 y NoSuchFieldError: int glId.
  • X-ray que deja el mundo vacío o que no muestra los minerales.
  • X-ray con Fabric API (Indigo).
  • Lista de bloques del X-ray editable desde el menú (clic derecho → Blocks).

Cómo instalar Aristois en 26.3

  1. Abrí Minecraft 26.3 una vez sin mods. Necesitás Java 25.
  2. Bajá EMC-F-v2-latest-26.3.jar y 26.3-Aristois.json de Releases.
  3. Bajá Aristois.jar de aristois.net.
  4. Seguí las rutas del README, elegí la versión 26.3-Aristois en el launcher y jugá.

Importante: poné los gráficos en OpenGL y no uses Sodium ni Iris en ese perfil.
